# Cahier des charges — TAXI SENIRAN AIBD

## Objectif
Mettre à disposition une plateforme numérique de réservation, supervision et gestion de taxis desservant l'AIBD.

## Acteurs
- Passager
- Chauffeur
- Superviseur AIBD
- Administrateur
- Gestionnaire financier

## MVP
### Passager
- compte téléphone
- demande immédiate
- destination
- estimation
- suivi
- historique
- notation

### Chauffeur
- disponibilité
- réception course
- acceptation
- navigation
- début/fin
- revenus

### Administration
- chauffeurs
- véhicules
- courses
- tarifs
- zones
- statistiques
- réclamations

## Règles AIBD
- seuls les taxis autorisés peuvent être activés;
- chaque véhicule possède une plaque et un identifiant interne;
- la file d'attente est conservée;
- toute attribution de course est journalisée;
- les rôles et permissions sont séparés.

## Évolutions
- géofencing AIBD;
- file intelligente;
- paiement mobile;
- QR code véhicule;
- SOS;
- partage de course;
- API partenaires hôtels/compagnies;
- statistiques BI;
- supervision temps réel.
